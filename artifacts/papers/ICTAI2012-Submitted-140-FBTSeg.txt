Abstract — This paper compares implementations of FBTSeg , a 
recent experimental segmentation method, and of NNTree , 
originally a neural network tree based segmentation  method, 
with traditional methods for the combination of cla ssifiers, 
namely bagging, boosting, and the traditional segme ntation using 
information gain to split. The tests were carried o ut using three 
data mining techniques with distinct characteristic s, specifically, 
linear regression, logistic regression, and multila yer perceptron 
neural networks, in four artificially built dataset s. The datasets 
design was aimed at understanding the specific circ umstances 
where each method, simple or combined, would presen t better 
performance. Results from this experiment suggest t hat blending 
classifiers using segmentation is a viable solution  to improve the 
performance of both statistic regressions, that bot h FBTSeg  and 
NNTree  are in general more predictive than the traditiona l 
segmentation, while bagging and boosting are more e ffective 
alternatives for improving neural networks models.  
Keywords-classification methods; segmentation; data  splitting; 
machine learning.  
I.   INTRODUCTION  
The results of decision models based on data depend  on 
both the quantity and the quality of the informatio n available 
for modeling. So, adequately predicting future even ts is a key 
element in the decision support systems used by mod ern 
companies. Choosing the predictive technique (for e xample, a 
statistic regression or a neural network) that is m ore adequate 
for some specific problem in hand may be an additio nal factor 
for improving accuracy [1] [2] [3] and this search goes beyond 
a single classifier.  
In fact, for a while, specialists and researchers h ave been 
investigating different combinations of multiple cl assifiers, 
with different parameters and sampling methods, loo king for 
the best configuration of ensembles to maximize the  
performance of the final solutions [4] [5] [6] [7].  
More specifically, to combine classifiers means usi ng 
several of them to create an integrated ensemble le arner with 
better performance than all the individual predicto rs used to 
create it.  
Ensembles usually improve results when there is goo d 
diversity among these learners [8]. Diversity exist s when 
different classifiers present different variances and biases in the 
training. The combination of predictors is aimed at maximizing 
the prediction power or some other performance meas ure [5]. 
Diversity can also be created using the same classi fier several 
times, changing, in some way, its parameters or the training set. 
Classic methods for combining multiple classifiers include 
bagging [5] [9], boosting [5] [9], stacking [4] [5] , and 
segmentation (decomposition) [10].  
Segmentation is the division of the available datas et in a 
number of sub-populations and the development of a prediction 
model for each segment; then, each example is predi cted 
according to the specific model that it belongs [10].   
This paper presents the results of experiments comp aring 
implementations of two newer segmentation methods, FBTSeg  
(Find Best Tree Segmentation) [11] – formerly RISKS EG [12] 
– and NNTree  (Neural Network Tree) [13], with the traditional 
segmentation using information gain as the metric t o choose 
the best split [14] (here we named it TradSeg ), as well as 
bagging and boosting.  
These five methods were combined with three base learners 
and tested using four artificially built datasets, with three 
sample sizes each.  
The three base learners chosen are linear regression (Linear 
Discriminant Analysis) [15], used to estimate the v alue of a 
dichotomic variable (0 or 1); (binary) logistic regression [15], a 
traditional technique of statistic inference; and m ultilayer 
perceptron neural network (MLP), trained with the 
backpropagation or Levenberg-Marquardt algorithms [16]. 
The rest of this paper is organized as follows. Our  
implementations of the three segmentation methods a re 
discussed in Section II. Section III introduces the used datasets. 
The experiments design and results are described in Section IV. 
Finally, Section V presents our conclusions and proposes future 
work. 
II.  SEGMENTATION METHODS IMPLEMENTATION  
The implementation of segmentation methods can be d one 
using different approaches. Many of them rely on su bjective 
strategies, based on previous knowledge of the prob lem and/or 
the data by an expert. Usually, they are based on ( a) the 
existence (or absence) of filled information in a n umber of 
selected attributes as a criterion for the split an d/or (b) the 
feeling of the expert based on his/her previous experience [14]. 

 
In the past, it has been suggested that it might no t be 
possible to create good segmentation structures wit hout the 
subjective knowledge of an expert [10]. However, methods and 
algorithms to find adequate segmentation structures  have 
already been proposed. These methods usually repres ent the 
segmentation structure as a tree and use exhaustive  or semi-
exhaustive search algorithms to choose the best seg mentation 
strategy [10]. 
This work concentrates on objective and systematic 
approaches. As already mentioned, the segmentation methods 
chosen for our experiments are: TradSeg  (the segmentation 
using information gain), NNTree , and FBTSeg . In all of them, 
the result is a tree of models (learners), with dis joint partitions 
of the training sample. 
The implementations of all combination methods have been 
developed using the language of the SAS Enterprise Miner 
software version 4.0 [17]. All three base classifie rs (MLP, 
linear regression and logistic regression) algorithms used in the 
tests were already implemented in the software.  
The selection of the base classifier to be used in each run 
was based on a parameter ( Inductors) of the aforementioned 
software. It is important to say the FBTSeg  implementation 
supports the use of different base classifiers in d ifferent nodes 
of the same model tree but this possibility was not  exploited in 
the experiments reported here. 
A.  NNTree – Neural Network Tree 
An NNTree [13] is a decision tree where each non-te rminal 
node has a neural network. Its original implementat ion uses an 
MLP to design the classification tree. The method r ecursively 
divides the training set trying to create leaves wi th elements 
from a single class – presumably, each non-terminal  node has 
elements from more than one class and uses a neural  network 
to separate them.  
The process has three main steps: splitting nodes, checking 
whether the new nodes should also be split, and lab eling 
terminal nodes.  
In other words, NNTrees are recursive classifiers t hat 
partition the training set aiming to obtain nodes w ith elements 
of a single class. An example of the classification  structure of 
NNTree, adapted from [13], is presented in Figure 1.  
Observe in the example that the MLP 1 node generated the 
terminal node A 12 , with instances of class II, as well as nodes 
A11  and A 13  with new neural networks MLP 2 and MLP 3, 
respectively. These last two MLPs then generated ot her 
terminal nodes (A 21 , …, A 2m , etc.) as well as other nodes 
containing MLPs (MLP 4 and MLP 5).  
Even though the original implementation only uses n eural 
networks, the version implemented for the experimen ts 
reported here is an adapted algorithm to also suppo rt both 
linear and logistic regressions in the non-terminal nodes. 
B.  FBTSeg – Find Best Tree Segmentation 
The FBTSeg method [11] aims to find a set of segmen ted 
models that improve the performance based on a tree built from 
divisions using attribute classes. It implements an  algorithm 
that selects the best segmentation through combinat ions of 
candidate nodes from a set of preselected attribute s (P), which 
is a parameter. In other words, after the attribute selection, each 
attribute class is used to split and the best segme ntation is 
chosen to improve the accuracy of the model for this node.  
Figure 1.  Example of NNTree 
The current implementation of FBTSeg  generates, for every 
node, two  segments with their specific models which, when 
combined, might generate better results than the up per node 
model, originating a binary tree. Thus, the method splits each 
relevant population in two segments, depending on w hether 
X0=0  or X0=1 , where X0 is a predictive variable. This is 
equivalent to building a model so that every other variable Y 
has two variables Y0 = (Y | X0=0) and  Y1 = (Y | X0=1)  [14].  
So, in all nodes that are candidates for segmentati on, the 
interactions of each (dichotomic) predictive variab le of the 
problem are tested with the other predictive variab les (using a 
statistic regression), building models correspondin g to each of 
them. Therefore, the number of models is the number  of 
variables available for the split. Then, the chosen  split is the 
one corresponding to the model with the best perfor mance, 
provided this combined segmented model improves the  results 
of the model of the original node. 
It is important to point out that the best option t o split each 
node should be chosen based on some specific metric  for 
optimizing the results of the problem, e.g. classif ication error, 
mean squared error, KS2 [18], ROC [19], and others.  
Additionally, it is worth mentioning that FBTSeg  can also 
use categorical variables with more than two classes to find the 
best segmentation.  
Similar to other supervised learning algorithms, FBTSeg  is 
prone to overfitting  and, therefore, it is advisable to create a 
validation dataset and to apply a cross-validation between the 
training and validation datasets. In this scenario,  the training 

dataset is used to train the predictors, while the validation 
dataset is used to compare the scores among the seg ments and 
for choosing the best segmentation.  
Algorithm 1, adapted from [12], presents pseudo-code for a 
possible implementation of FBTSeg  showing the search for 
candidate segmentations. The first loop selects the best variable 
and the second chooses the category of this variabl e that may 
be used to split the data. So, after selecting the variable ( Var ) 
with the best regression results in the interaction with the other 
variables (factorial), all the possible binary comb inations of 
this variable categories are tested to find the best category ( Cat ) 
and generate the best pair of segments, one for " Var  = Cat " and 
another for “ Var  ≠ Cat ”. After the segmentation, the predictive 
performance of the suggested pair of segments is co mpared to 
that of the upper node. The segmentation is confirm ed if it 
improves the results of the upper node. As in decision trees, the 
segmentation continues until some stop criterion is  reached. 
The final result is a set of models generated from disjoint 
subsets of the training data. 
The main parameters of FBTSeg  are:  
P:  Selected candidate variables. The FBTSEG  method 
assumes there is a set P of attribute variables available for the 
segmentations. In other words, the method permits c hoosing a 
priori the variables eligible to be used in the seg mentations. 
The base algorithm works with categorical variables. 
D:  Performance metric to be calculated and evaluated for 
choosing the best segmentation. Metrics available in the current 
implementation of FBTSeg  are: classification error, KS2 [18], 
ROC [19], and Odds Ratio [14].  
f:  Combination function or meta-learner. The result o f each 
segmentation possibility needs to be joined, such t hat D can be 
calculated and its result can be compared to those of the other 
segmentation possibilities, including the model of the upper 
node (without segmentation). The FBTSeg  implementation can 
use Stacking  [4] or Marginal Odds  [14] as the meta-learner. 
B:  Stop criteria. The available options are minimum 
number of examples in a segment; minimum gain and 
maximum loss of performance acceptable in segmentat ions 
(percentages); and maximum depth of the segmentatio n tree. 
The minimum number of examples in a segment prevent s non-
representative models from being trained as well as  categories 
without a relevant number of examples from being te sted. The 
maximum depth of the segmentation tree helps limiti ng the 
execution time.  
FactorialTechniqu e: Prediction technique used in the 
selection of candidate variables for the segmentati on. We used 
logistic regression but RNA and SVM [5] could also be used. 
NVarTested: Number of variables that will be selected by 
the prediction technique ( FactorialTechniqu e). If the chosen 
value is 1 (one), only the best variable will be se lected, as 
illustrated in Algorithm 1.  
ValidationSize:  Size of the validation dataset, defined as a 
percentage of the training dataset size. A validati on dataset is 
used for the calculation of the performance metric (D) as well 
as in techniques that require it in the training pr ocess, such as 
neural networks, which use it to tackle overfitting.  
The FBTSeg  method has the following steps:  
Step 1 (Generate Subsets):  the method builds a subset of P 
with k categorical variables , using Factorial Models to select 
the best splits according to metric D. In other words, the 
regressions with the best performance indicate the variables 
that should be chosen for splitting. In theory, the  best 
performance regression indicates the best variable for the 
segmentation. However, D might present relevant variances 
and the results of several regressions might be sta tistically 
equivalent.  
After the k variables are selected, a set V={v1,v2,...vk} is 
built. Then, for each candidate variable vi, the split process is 
run, i.e., the set Ci={ci1 ,ci2 ,...,cil} of categories of  vi is built and 
the records of the relevant node are separated. Eac h split 
generates two segments, with those records satisfyi ng vi = c ij  
and vi ≠ c ij , respectively, for all elements of Ci. However, it is 
important to notice that the generated segments are  subject to 
the stop criterion minimum number of examples in a segment .  
Step 2 (Generate Classifiers):  for each of the segments 
generated in step 1, a new classifier is built. Alt hough the 
theory behind the method considers that interactions among the 
variables are based on statistic regressions, class ifiers of the 
segments can also be built using other regression t echniques 
such as neural networks.
 
Step 3 (Select Best Segmentation) : based on the list of 
results of the metric D for each pair of segments generated, the 
best result found indicates the variable and category that should 
be used in the possible segmentation of the node. N ote that not 
all segmentation multi-classifiers will improve the performance 
of the corresponding upper node original classifier [10].  
Step 4 (Recursive Search) : after all the terminal nodes in 
the current level of the tree have passed the split  process, and 
provided no stop criterion has been reached, the se gmented 
nodes created in this level are submitted to the sa me process, 
possibly originating a new level in the tree.  
Step 5 (Categorization of Numeric Variables): as in 
decision trees, segmentations can also use numeric variables to 
create split rules. In decision trees, the algorithm finds the point 
of a numeric interval that best splits the data bas ed on a metric 
to separate the values of the target variable, for example, 
entropy, information gain, chi-squared, etc. [10].  
The FBTSeg  approach is similar, but it searches the point 
where the split leads to the most distinct data sub groups 
regarding the target and predictive variables, i.e. , the point 
where the interaction among these variables is greater.  
Specifically, the original numeric variable is cate gorized in 
n parts, generating an equivalent categorical variab le that 
represents it. The best value for n can either be defined 
experimentally or be chosen by an expert with previ ous 
experience on the variable distribution.

IV.  EXPERIMENTS DESIGN AND RESULTS  
Linear regression, logistic regression, and neural networks 
were used as base classifiers (control) to be compa red with the 
combination methods. Significance tests are execute d when a 
combined method has results that are better than th ose of the 
base classifier, to make sure they are statistically different. 
For all datasets, we created 30 replications of eac h 
experiment ( k), to calculate confidence intervals and 
hypotheses tests. Each replication used a separate dataset; the 
objective was to compare the performance of the com bination 
methods in controlled datasets of different sizes.  
Since all numeric variables of the four datasets were created 
to be continuous in the [0, 1] interval, no preproc essing was 
needed for training the classifiers. However, becau se our 
implementations of both TradSeg and FBTSeg only acc ept 
categorical variables in their splitting processes,  for each 
numeric variable, we created four categories, each with 
approximately 25% of the data. It is worth emphasiz ing that 
these categorical variables were only used to split data. 
A.  Defining Experiment Parameters 
In both statistic regressions, it was not necessary  to choose 
variables or parameters because the datasets have b een 
generated so that the target variable had a signifi cant 
relationship with all predictive variables.  
In the MLP neural network, we tested all the possib le 
combinations of the two training algorithms (backpr opagation 
and Levenberg-Marquardt) with 3, 10, and 20 neurons  in one  
hidden layer. The chosen activation function was si gmoid 
logistic function having the minimum squared error on the 
cross-validation set as the training stopping crite rion. We used 
the standard learning rate of SAS Enterprise Miner [17], 
version 4.0, which cannot be modified in this versi on of the 
software. We then chose the best configuration for the classifier 
(single or combined) in the group of experiments. 
For bagging, the chosen size for the re-samples was the size 
of the original dataset, but allowing repetitions, which is very 
common [9]. Based on pre-experiments, for both bagg ing and 
boosting, the chosen number of re-samples was 25, t he same 
number used in [21].  
For the segmentation methods, we used 3 (three) as the 
maximum depth of the tree because, in preliminary t ests, we 
observed that the best segmentations were in these levels. For 
the minimum size of a leaf node we chose 10%, a siz e we 
judged appropriate, considering the sizes of the da tasets. The 
metric used to evaluate the results of the experime nts was the 
classification error.  
It is important to emphasize that our implementatio n of the 
segmentation methods used a validation dataset to d etermine if 
there was a gain (or not) in each segmentation poss ible. The 
validation dataset was 25% of the complete dataset and the 
same sample was used in the validation of the MLP .

Notice that, in all ensembles using this dataset, t he 
classification errors of the statistic regressions were not much 
affected by the sample size variation. In addition,  MLP results 
were frequently the best and the sample size had si gnificant 
effect on them, behavior that was also observed and  discussed 
by Kiang [3].  
Results of Table III confirm that, because dataset 3 only has 
simple dependencies, the ensembles were not very ef ficient. In 
fact, in very few configurations the results were s ignificantly 
better than those of the corresponding base classif iers and 
several results were indeed worse.

Our main conclusions are: 
• Creating ensembles is only worth it when the datase t 
has complex dependencies; 
• Bagging and boosting can improve the performance of  
MLP neural network learners; 
• Segmentation methods can be very efficient to impro ve 
the performance of linear regression and logistic 
regression classifiers; and  
• Both FBTSeg  and NNTree  are, in most cases, more 
predictive than the segmentation by information gain. 
The FBTSeg  method improved the results of the statistic 
regressions as base classifiers in all configuratio ns using 
datasets 1, 2, and 4, and achieved the top results with both 
regressions in dataset 1. On the other hand, its performance was 
much weaker with MLP as well as in dataset 3.  
The performance of NNTree  was very similar to that of 
FBTSeg  in most configurations. Even though NNTree  was not  
originally developed to work with the statistic reg ressions, it 
has also improved the results of these base classif iers in all 
configurations using datasets 1, 2, and 4, even ach ieving the 
top results with both regressions in dataset 2. How ever, in 
dataset 3, it did not significantly improve any results at all.  
Other experiments with the same segmentation method s 
and the same base classifiers using a number of dat asets of the 
UCI repository [22] were recently reported [11] and  yielded 
similar results. Specifically, the segmentations methods did not 
significantly improve the results of experiments us ing MLP as 
the base classifier.  
Notice that, in most cases, the results using MLP a s base 
learner were much better than those using linear re gression, a 
classifier known to be weaker [3]. However, the use of FBTSeg  
(and of the other segmentation methods too) often led to results 
that are much closer to the base results obtained with MLP. 
An advantage of using segmentation, not discussed y et, is 
preserving the explanatory characteristic of the te chnique used 
to generate the scores. This happens because segmen tation 
methods only use one model per prediction whereas b oth 
bagging  and  boosting can  use several. So, explaining the scores 
only depends on the techniques used.  
For example, linear regression can be easily explained since 
its result is based on a linear equation. On the ot her hand, the 
results obtained with neural networks are, in gener al, harder to 
explain. This fact and the indication that segmenta tions 
together with linear regression might achieve resul ts that are 
similar to those obtained with MLP as base learner suggest that 
segmentations could be a viable choice for problems  where 
explaining the results is an essential requirement. 
Future work includes studying the behavior of the 
segmentation methods using other learners such as K NN  [5], 
SVM [5], etc. These and others can be tested either individually 
or using different techniques in the same training.  Another 
possible direction is to compare the three segmenta tion 
methods with other ensemble platforms such as the o nes 
presented in [6].
